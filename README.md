When adding a solution, choose the folder that best matches its code or problem topic. Use the existing folders before adding a new category.

The existing `categorize_leetcode.py` helper guesses categories from filenames. Its guesses can differ from the categories above; review the code and proposed destinations before applying its moves.

## Usage

Use Python 3.10 or newer. From the repository root, run a file by its path:

```sh
python3 dp/HouseRobber.py
```

Or run it from its topic folder:

```sh
cd dp
python3 HouseRobber.py
```

Many files include sample inputs and print their results. Files containing only a solution class need an instance and method call or the corresponding LeetCode judge. Some files are still incomplete attempts.
